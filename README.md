# Hutchinson (hutchinson)

Hutchinson SA is a French global Tier 1 automotive supplier headquartered in Paris, a subsidiary of TotalEnergies. Hutchinson designs and manufactures anti-vibration systems, sealing systems, fluid transfer, precision rubber components, and aerospace systems for the automotive, aerospace, defense, and industrial sectors.
